# 参考作品：几猫国产3A大作_V1.html

来自本次用户上传附件的静态分析与一次 Chromium 运行观测。这里只保存技术事实，不包含附件源码、模型或引擎副本，也不能验证其具体生成模型或作者身份。

## 文件测量

- 原始文件：1,425,707 字节（约 1.43 MB / 1.36 MiB）。
- Python gzip 默认等级、mtime=0：445,935 字节。
- 按源码边界估算：Three.js/打包基础 701,819 字节；游戏代码 691,788 字节；HTML/CSS 等 32,100 字节。
- Three.js r180 内联；测试中只有 HTML 文档请求，外部资源被阻断后仍进入游戏。

## 实现事实

- 参数化几何搭建港口、枪械、机械飞鸥、机械犬。
- GPU 着色器生成 albedo / normal / ORM；Canvas 绘制文字和标牌。
- PBR、软阴影、AO、体积雾、平面反射、环境探针、曝光与色调映射、镜头后期。
- 57 类音效/音乐/混响生成项，Web Audio 播放程序生成采样。
- 胶囊体/包围盒碰撞、射线命中、网格 A*、敌人有限状态机。
- 约 80×60 世界单位活动边界，三个中继目标，两类敌人，同时存活上限 9。
- 按材质静态合并、对象池、画质分档、动态分辨率与效果降级。

## 一次运行快照

1280×720 输出、中档，内部渲染 1088×612；494 次绘制调用、约 2,910,447 次提交三角形、199 个几何对象、143 个纹理对象、115 个着色程序。音频当时已有 86 个缓冲区，另有生成队列。

这些数字是当时视角的快照；多 pass 重复提交包含在三角形统计中，纹理数量不等于纹理字节或独立美术资源数量。

运行环境使用 SwiftShader 软件渲染，因而不提供可用于真实 GPU 体验判断的帧率/启动时间基准。原始测试脚本的 `runtime.json.boot` 包含截图等后续开销，不能把它当冷启动指标。

## 可迁移原则

保存生成规则而非成品资源；利用规则结构和材质共享；把视觉投入集中在主光、湿地反射、空气感、近景武器和操作反馈；限制内容规模；把下载大小、运行内存和渲染成本分别预算。

本 Skill 的预算是后续项目默认目标，不代表原作品已通过全部验收。原作品没有实现本 Skill 的诊断接口，因此用 reference 适配器复测时，玩法、完整资源审计和全部验收视角仍会标记未验证。
