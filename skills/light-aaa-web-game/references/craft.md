# 把一段玩法做细

用实际镜头走完玩家最常经历的几秒，找出一个具体的创作决定。以下做法按作品取用，尤其适合已有可玩原型却仍显单薄的时候。

| 玩家感受到的落差 | 制作时可以改变什么 | 用什么判断取舍 |
| --- | --- | --- |
| 地方看起来都一样 | 给近处安排人会接触、使用或维护的物件，中景用结构显出路线，远景留一处可辨的地标。例如维修站的线缆从电柜通向待修设备，中断的一段还能交代故障发生在哪。按画面尺度复用模块、调整磨损和布置密度。 | 关掉指路标记，按正常速度从两侧经过路口。看玩家能否凭物件关系认出方向，并看见下一个可操作目标。 |
| 布景精细，但操作像切换图片 | 先确定哪一处接触、哪一刻传力。让重量、支撑面和入射速度决定后面的位移、次要部件的滞后与停稳。动作中断时从当前姿态衔接。轻巧、僵硬或突然停止也可以符合角色设定。 | 在正式镜头实时播放从准备到静止的片段，再逐帧定位异常。对台球看碰库后方向和速度，对飞行器看哪一侧先着地及重心如何落定。 |
| 物件有不同外观，碰起来像同一种东西 | 从实际接触面取得材质、方向和力度，让声音、短暂变化、残留分别使用相关信息。松雪可用轻量的局部凹面和受光边缘，金属可保留擦纹、短响。共享材质配方，先在玩家会靠近的一处做出可信的差异。 | 从相同高度和方向触碰两种表面。绕到侧面、待短暂效果消散再看。贴花、法线或几何中，选择在本作实际观看距离能表现形状的最低成本做法。 |
| 环境有很多声音，却听不出身在何处 | 找出地点里持续发声的东西以及会移动的声源。用门口的遮挡、距离、设备运转状态改变混音。短促的事件给起音留出空间，重复声先按动作和材质选一族，再在族内做变体。 | 沿同一路径进出室内或靠近声源。关掉一层重听，看玩家失去了哪个判断。叙事中的留白也可以是刻意设计。 |
| HUD 很完整，忙起来却读不懂 | 在玩家必须作决定的那一刻排信息优先级。常驻量给稳定位置，临时提示靠近所指对象或留出游玩区域。暂停、不可用和恢复用真实状态驱动，并把焦点还到可继续操作的位置。 | 用最长目标名、变化中的数字、弹层和窄屏试一次真实操作。能否看见当下要决定的事，操作后能否一眼认出结果。 |
| 内容更多了，玩法仍单调 | 用灰盒先排节奏。先在低压力下让玩家认识一个规律，再安排可以利用它的选择，最后改变一个条件。赛车可通过弯前地标决定何时减速，谜题可让上次失败留下这次能用的信息。 | 把新增装饰或提示暂时移开，试不同决策是否真的带来不同结果。再恢复美术并确认线索在最终光照和 UI 下仍可读。 |

为最重要的一段保留能复玩的前后版本，用同一视角、输入和种子比较。共享绝对时刻的对照适合验同步，完整、不暂停的回放适合判断节奏。将选择转成[专项用例](focused-checks.md)，只要求对本作有意义的表现。
