# 1

以当前完整能力作为发布版本 `1`；此前内部版本号仅在历史验证记录中保留。新项目的验收预算与诊断接口使用第 3 版。

- 通用模板以项目声明的核心操作、代表负载和可见结果验收。已有第 2 版射击项目可继续使用原配置和证据字段。
- 画质打磨增加代表物体的近景和移动对照，按同路线比较帧耗时。材质投影、室内反射和远处细线处理按场景选用。

- 增加以玩家目标、参考品质样板和实际体验为起点的设计流程。
- 增加问题 → 假设 → 失败回归 → 修改 → 对比 → 回归 → 规则沉淀的闭环。
- 单 HTML、入口之后零额外网络请求成为明确硬约束，增强真实浏览器请求与尝试审计。
- 增加逐次动作与实际主画面提交关联，检查玩法结果与可见反馈；动态画面必须单独审查。
- 增加 3 次冷启动、5 次重开、60 秒活跃游玩、300 秒持续运行和帧节奏变体。使用特效池的作品可选复用检查。
- 最终审查增加玩家体验证据；P0/P1 未解决、旧构建证据、缺少修改前后/回归均不能过关。
- 保留早期内部版本的结果和限制；没有把旧游戏或新测试器反例结果冒充当前版本的游戏质量认证。
