# 单图生成 8K 全景

交付一张带 GPano 元数据的 8192×4096 JPEG。用户需要网页时，另交付可拖动、可缩放的查看器。原画提供的视觉证据只覆盖前方一部分；向用户说明画外景物是依据画风和光照补绘的。

## 制作

1. **定下原图在球面上的位置。** 看原图，记录需要保留的主体、相互位置、数量、画材、光线和地平线。普通镜头用透视投影。宽幅插画如果以近似均匀的比例横向展开，可以用柱面投影。按 EXIF、画面透视或合理估计设置水平视场，把地平线写成距顶部的高度比例。用 `init` 投影出灰底的 2∶1 布局，核对主体比例再补画。[脚本与工作目录](references/runbook.md)
2. **先画整圈构图。** 用可用的图像编辑工具（如 ImageGen），把布局作为第一张编辑图、原图作为细节参考。保持有色区域的位置和比例，把灰区补成连续的天空、侧后方环境和脚下。左右边缘在球面背后相接。检查主体是否被重复、水平线是否错位，保存为 `base.png`。[两阶段补画提示词](references/painting.md)
3. **为清晰度单独分配像素。** 在 `scene.json` 规划有重叠的镜头，优先照顾近处建筑、植被和接缝。六个初始方向可按画面增减。把重要区域拆成更窄的视角，宽视角过渡层放前面，细节近景放后面。运行 `guides`，逐张以其透视引导图为编辑目标，按原画笔触绘出可辨的局部细节，把原生分辨率的回图存作对应的 `paint.png`。将背缝、天顶和地底放进各自镜头的中心检查。
4. **配准、拼回、锁定原画。** `assemble` 将局部回图对齐各自的引导图，约束大轮廓位移，匹配低频色彩，羽化重叠区，最后从原文件重新投影主体。先用小尺寸检查构图，再出 8192×4096 无损母版和 `coverage.png`。覆盖图中绿色为保留原图，蓝色为接近目标像素密度的补绘，黄色为密度偏低或落在羽化边缘，红色为主要使用整圈底图。看可辨的线条和纹理来判断真实清晰度。
5. **验收并交付。** 用 `view` 固定同一组 yaw、pitch、hfov 和输出宽高，对照底图和成品。检查原主体、细节最密的区域、±180° 背缝两侧和两个极点。发现重影就回到对应引导图重新配准或补画。用 `export.py` 生成带完整 2∶1 GPano 字段的 JPEG。

## 网页和局部返修

- 用户需要手机网页时，用 `export.py` 的 `--web` 选项生成查看器。已有完整、清晰的 2∶1 球面母版时可以直接从这里开始。按本次授权的访问范围发布，改已有站点时复用原项目。交付公开链接前，用无登录会话打开实际网址，验证触摸拖动和双指缩放确实改变画面，确认当前视角的高清切片已成功加载。[网页参数及验收方法](references/runbook.md#手机网页)
- 收到模糊截图时，先定位画中地标和相机视角。固定视口与缩放，在最高可用切片加载完以后比较同位置的母版透视图。母版本身发软时补绘该区域；母版清楚而网页发软时核对请求的切片级别、画布实际像素与设备像素比。用同一相机交付前后对比和直达链接。
