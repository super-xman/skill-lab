# 使用示例
- **海滨照片**：「使用 vintage-travel-gouache-painterly，将我的海滨酒店照片改画成笔触明显的复古旅行海报，海浪和云朵允许更有油画涂抹感，保留酒店位置与海堤。」
- **荒漠照片**：「保留荒漠路面、远山、独行者和空旷感；用有方向的厚实短笔触表现沙地、山石与云，适度扩景。」
- **人物头像**：「保留人物身份、服装与姿态，背景可以适量补充自然元素，人物居中并保证圆形裁切安全。」
- **严格保真**：「不增加任何物件，只改变为 painterly gouache 画法。」
- **原创场景**：「画一幅山间火车旅行插画，不写标题，以层次清晰的复古海报构图和较明显的油画式水粉笔触表现。」
