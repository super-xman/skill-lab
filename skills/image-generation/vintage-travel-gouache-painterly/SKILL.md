# 复古旅行海报 · Painterly Gouache（油画涂抹感）

## 核心定位
面向喜欢**明显颜料涂抹痕迹**、活跃云层、丰富海浪和山石色块的用户。风格结合20世纪30—60年代欧美旅行宣传画、opaque gouache、不透明层叠色块和 painterly oil-brush handling。比 `vintage-travel-gouache-refined` 的笔触更厚、更自由、更有运动感，但保持商业插画式的主体识别与构图秩序。

**本 Skill 完全依据文字规则工作。** 只把用户提供的目标图片用于图生图；不请求、不读取、不上传任何额外风格参考图。README 和 `examples/` 中的图片仅供人类查看，**不能自动作为生成器的风格输入**。

## 何时使用
当用户明确想要复古旅行海报、水粉油画、可见涂抹笔触、较浓郁的绘画质地、painterly vintage travel poster 等效果时使用。用户只是请求分析/解释/修改文档时不自动出图。

## 内容约束
- **不变项**：主角与人物可见特征、姿势、道具、重要建筑/地标、原图主体位置、关键场景关系、指定文字、Logo 和颜色。
- **L0 严格转换**：原图只变绘画风格，不增删实物，不重构构图。
- **L1 适度扩展（默认）**：允许补全画布边缘、添加少量自然云朵、植被、地形、远景及光影层次，优化留白，但不改变故事与主角。
- **L2 自由扩展**：仅用户明确要求时扩大场景、丰富配景；仍保留不可变项。
- 图生图默认沿用目标图宽高比；多张输入图片默认**分别出图**，除非明确要求拼贴或组图。

## 无参考图的画法 DNA
1. **造型**：20世纪中期旅游海报的优雅概括、清楚剪影、景深与视觉焦点。不是照片滤镜、矢量扁平或动漫。
2. **材料**：opaque matte gouache with painterly oil-like brush handling；颜色通过不透明颜料叠盖，留有手绘刮擦和色块断边，但不模拟夸张的真实颜料浮雕。
3. **天空**：允许肉眼可见的短中程笔触、柔和扫涂与色块层次，尤其在云层附近；天空纹理比 refined 版明显，但仍需有大色面的呼吸感。避免不受控制的满屏同向斜线或旋涡噪声。
4. **云朵**：奶油黄、桃橙与灰蓝/淡紫色块交叠，体积饱满、笔触清晰，允许局部厚涂。
5. **海浪/山石/植被**：海浪使用弧形、水平相接的节奏短笔触与碎高光；岩石和道路沿结构转折用较密集的笔触；树叶使用成簇点划。
6. **建筑/人物**：几何结构、视角、五官与剪影清楚；笔触可见但不破坏可识别特征。
7. **配色**：深海青、灰蓝、金黄、奶油桃色与陶土色的冷暖对比为**示例关系**，不是固定滤镜；尊重原图的季节、天气与固有颜色。哑光、柔暖、复古，不要荧光或金属光泽。

## 推荐相对笔触强度
天空 3/5；云朵 4/5；海水 4/5；岩石/地面 4/5；植被 3/5；人物/建筑 2/5。此表只描述相对视觉强度，不是生成 API 参数。让风格清晰可辨，但不应粗糙到看不出结构。

## 生成流程
1. 从目标图/文字提炼主体、构图、光源、不可变细节、输出比例与扩景等级。
2. 以 `references/style-guide.md` 的视觉规则建立绘画质地，再用 `references/prompt-templates.md` 构建完整中英提示词。
3. 图生图：**只提供目标图**，并使用文字描述画风；创作新图时仅提供文字场景设定。不得暗自使用仓库内样例图片或上一轮生成图作为参考。
4. 不自行增加邮轮、灯塔、巨型太阳等通用模板物；新增元素必须属于目标环境且不抢主体。
5. 生成后核对人物/地标与原图一致、笔触可见、冷暖关系协调、背景扩展合理、无额外标题和水印。若纹理太满，局部减轻笔触而非把整幅画变成平滑数字渐变。

## 质量门槛
- 主体与重要细节保真；构图比例正确，目标图不被无故裁切。
- 能读出具有油画式涂抹感的不透明颜料短笔触，但建筑人物仍精致。
- 天空云层更有手绘动感，不是无差别刮擦噪声。
- 海浪、岩石、树冠拥有各自合理的方向与肌理。
- 新增景物克制、合理；不凭空添加标题、标志、关键角色。
- 不依赖风格参考图，`examples/` 仅作为 README 展示素材。
