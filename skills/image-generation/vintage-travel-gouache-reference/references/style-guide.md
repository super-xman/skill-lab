# 风格指南：参考图《海边度假》

> 这是从用户提供的 2048×731 横幅插画中提炼的**画风**规范，不是必须复制的画面配置。色值通过图像像素聚类归纳，为**近似代表色**，不是设计稿的强制 RGB 标准。

## 1. 视觉归属

- **基础流派**：Mid-century Vintage Travel Poster / Vintage Commercial Illustration；主要观感为复古欧美旅游宣传画。
- **绘画媒介**：Opaque Gouache（不透明水粉）与 Painterly Brushwork（绘画性笔触）；局部带软质轻厚涂视觉效果。
- **不是**：透明水彩风、照片滤镜、扁平矢量海报、CG 3D、动漫渲染、极粗重梵高式厚油彩。
- **整体调性**：浪漫、悠闲、明亮、温暖、怀旧、适度理想化；清晰但不机械的轮廓。

## 3. 具体笔触规则

- 可见、方向明确的短笔触；局部不规则边缘与跳跃色点，避免每一处都被平滑混合。
- 大色块先建立体积与光照，再使用密集的小短笔触绘制云层、树冠、波纹、山石、船体/建筑等细节。
- 光照区域使用奶油色或暖黄薄覆盖的观感；阴影不是纯黑，而由更冷的灰蓝、靛青、橄榄灰叠加。
- 水面若存在，采用方向连贯的弧线/水平短笔触和分层反光；没有水体的场景不强行加入波浪纹样。
- 云层若存在，用厚实、卷曲、块状、不完全对称的造型，保留颜色堆叠与层次；不强制日落云。
- 建筑形体可以适度概括，但重要透视、门窗数量与地标特征须由目标图决定。
- 颗粒为低到中等强度，具有印刷/纸张纹理，不要变成脏污、强噪点或严重破损。

## 4. 构图与形状

原图具有大前景主体、宽广水面、远处层叠山体、沿岸建筑的强纵深与均衡构图。这是可学习的**层级清晰、主次明确、韵律感强**，不是模板里必须有的场景对象。

- 新创作：突出一个视觉中心，辅以远中近景节奏；允许适度理想化的比例表达。
- 风格迁移：忠实保留目标图的核心主体和关键关系；默认允许轻微调整取景、延展画布边缘、填补背景空缺与加强空间层次，但不增加/替换主角。用户要求严格复刻时保持构图和视角不变。
- 人物肖像：面部、发型、姿态、配饰优先准确；笔触只能改变渲染方式。
- 头像圆形裁切：主体要居中，边缘有安全空间，不要切掉头部、马头、旗帜或其他关键部位。
- 原图约 2.8:1 的超宽画幅只是其具体构图，不属于风格必要条件。

## 5. 可控内容扩展规范

用户已允许**适当扩展图片内容**，默认采用 Level 1（适度扩展），不再把目标图中的每一处背景元素和原始取景视为绝对不能变动。

- **适合扩展**：延长天空、山脉、河流、街道和建筑群的合理连续部分；增加与季节和地点相称的云层、植物、石块、光斑、室内小摆件；适度完善前中后景；为圆形裁切拉远主体并补足边缘。
- **要谨慎**：增加次要远景行人、动物、交通工具等容易改变故事信息的元素；只有在场景确实需要且用户没有人数/数量限制时才考虑，并保持弱存在感。
- **默认禁止**：改变人物身份、动作、主要道具、已知地标结构、重要数量关系；凭空增加新的关键人物或剧情；添加无依据文字；直接复制参考图中的邮轮、灯塔、巨型太阳等标志物。
- **画幅适配**：如果用户指定新的比例，优先采用向外扩图（outpainting）而非截断重要主体；保持透视、地平线、光源和材质的连续性。
- **强度选择**：Level 0 为严格保留，Level 1 为默认适度扩展，Level 2 为用户明确授权的较自由创作。

## 6. 分层优先级

1. 用户文字明确要求（内容、文字、色彩和用途）。
2. 目标图关键内容（人物特征、重要数量关系、关键建筑结构、时间地点）。
3. 目标图非关键背景与可扩展内容（只在不冲突时适度调整）。
4. 参考图的绘画媒介和色彩关系。
5. 参考图的构图气质与场景特征（仅在用户要求时借鉴）。

## 7. 质量红线

- 内容扩展错误：机械照搬参考图的邮轮、灯塔、巨大圆日、海湾或拱廊；或添加与目标环境无关、喧宾夺主的物体。
- 过拟合：除了主角外的背景与参考图几乎相同。
- 质感偏差：过度光滑，像 AI 3D 或数码摄影滤镜；或过度透明，像洇染水彩。
- 光色偏差：全图高亮高饱和霓虹色，丧失柔和哑光；或全部糊成单一黄橙滤镜。
- 输出偏差：擅自改画幅、自动加标题、人物偏离原图身份、背景与主体遮挡冲突。
