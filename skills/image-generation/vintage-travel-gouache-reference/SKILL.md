# 复古旅行海报厚涂风 · Vintage Travel Gouache · Reference-guided (v1.1)

## 本 Skill 的目标

把**视觉风格**固化为可复用的工作流程，而不是把参考图中的**具体景物**固定成模板。以 `assets/style-reference.webp`（原始《海边度假》画面的高清 WebP 参考图）作为唯一默认风格锚点，产出具有「20 世纪中期欧美旅游海报 × 不透明水粉 × 轻度油画厚涂」气质的作品。

始终遵守：**迁移画法，不搬运参考图的具体画面；核心主体保真，周边内容允许适度艺术化扩展。**

## 何时启用

当用户提到「复古旅行海报厚涂风」「海边度假同款画风」「这张邮轮海报的风格」「Gouache / 不透明水粉」「Mid-century travel poster」并希望新建或修改图像时启用。用户仅要求分析、讲解该风格时，也可用本 Skill 解释，但**不自行创建图片**。

## 随附材料与阅读顺序

1. `assets/style-reference.webp`：用户提供的绘画参考原图。尽量实际查看或作为风格图片输入；**仅供风格借鉴**。
2. `references/style-guide.md`：风格 DNA、从参考图中提取的近似色板、形状与笔触规则。
3. `references/prompt-templates.md`：可直接套用的中文版、英文版提示词；负面词和质量检查。
4. `examples/example-requests.md`：人像、城市、动物、新场景等调用案例。

## 操作流程

### 1. 识别任务类型

- **风格迁移与适度扩展（默认）**：有目标图片 → 保留核心主体、姿态、识别特征与关键场景关系；可少量补充背景、空间层次与符合主题的装饰元素，并在不破坏主体的前提下优化取景。
- **严格风格迁移**：用户明确说“原样保留”“不要增加内容”“仅改画风”等 → 保留主体、构图、比例、姿态及必要细节，不主动扩展内容。
- **全新创作**：没有目标图片，但给出了场景设定 → 生成原创画面，应用本 Skill 的视觉风格。
- **风格说明/提示词**：用户只要描述或提示词 → 输出分析/可复制提示词；不要擅自出图。

输入检查：目标图或场景描述、人物/物体必保留的特征、画幅、裁切用途、色彩/时间天气限制、文字处理需求。已明确的要求不重复询问；缺少非核心信息时选合理默认值。画幅与输出目标由用户指令决定，**不要沿用参考图的超宽画幅作为默认**。

### 2. 建立「不可变项」与「可扩展项」

- **不可变项（优先级最高）**：用户指定的主体、人物身份与面部/可见特征、关键表情姿态、标志性服饰道具、重要建筑/地标形态、情节关系、明确禁止元素、需要准确保留的文字/Logo、品牌/阵营主题色。
- **可迁移项**：绘画媒介、笔触形态、色块分层、颗粒肌理、光影绘画表达、整体复古氛围，以及不与不可变项冲突的辅助配色。
- **可扩展项（默认适度允许）**：合理补齐原图未画出的背景与边缘、延展天空/地面/山体/水面/街道、增加少量符合原场景的植被/云层/光影/建筑远景/环境小物件、强化前中后景纵深、适度拉远或重构留白以适配画幅和头像裁切。
- **参考图不可机械移植**：参考图的邮轮、灯塔、帆船、海岸小镇、巨型太阳、拱廊、棕榈树或浪花不是通用配件。只有**与目标主题本身合理相关、且有独立创作必要**时才可使用同类环境元素，不得照搬参考图具体物体、布局或视觉标识。

冲突处理：用户明确内容约束 > 用户明确色彩/时间/用途 > 目标图核心事实 > 可扩展空间 > 本 Skill 风格建议。不要为了画风把夜景擅自改为日落、山谷改为海滨、真实人物改成其他面孔。

### 2.1 内容扩展强度

- **0｜严格复刻**：当用户要求“原样保留”“仅改变风格”“不要添加”时启用；不增删内容，只变画法。
- **1｜适度扩展（默认）**：保留画面主旨与主体比例；允许背景补全、局部环境装饰和轻微取景优化，附加内容应从属于主体。
- **2｜较自由扩展**：仅当用户明确要求“丰富场景”“发挥想象”“可以大幅扩展”时启用；可以明显拓展世界观与环境叙事，但仍尊重用户指定的不可变项。

**扩展判断法**：每个新增元素都应回答“是否自然属于这个场景、是否强化主题、是否不抢主体、是否不与原图冲突”；任一项为否则不添加。默认不加入重要新人物、标志性新地标、虚构文字或改变既有故事关系。

### 3. 注入风格 DNA

使用以下**组合**而不是单独的“油画”“水彩”：

1. **复古宣传画气质**：1930—1960 年代欧美观光宣传海报的浪漫、明朗、装饰性构图；保留精致物体形态而非粗糙卡通。
2. **不透明水粉 Gouache**：多层哑光颜料，边缘由笔触塑造，色块局部交叠；不是大量透明水彩洇染。
3. **轻度 Painterly Impasto**：短而清晰的手绘笔触、局部厚涂感、细腻画布/纸张肌理；不要夸张浮雕式油漆堆积。
4. **光色关系**：暖金、奶油橙的日照感与海蓝、松石青的冷色块构成柔和对比；阴影偏灰蓝、蓝紫或柔和冷色。若原场景不适合日照，只迁移层次和冷暖逻辑。
5. **形状与细节**：建筑、人物、自然景物采用准确结构 + 适度艺术化简化；近景笔触细节更清晰，远景以层次、空气透视和小色块处理。
6. **整体观感**：色彩浓郁但不荧光、柔和且具年代感、可见人工画笔痕迹，避免数码塑料感、照片写实和过度平滑渐变。

更精确的色板与实施细节见 `references/style-guide.md`。

### 4. 根据任务生成提示词

优先引用 `references/prompt-templates.md` 中的相应模板，并写入具体目标内容及内容扩展强度（默认 1）。指明输入角色：

- 风格参考 = `assets/style-reference.webp`：**只负责 style**。
- 目标图片 = 用户指定的原图：**约束核心 content / composition / identity**；对背景和画幅允许有边界的合理扩展。

如果工具支持图像编辑/图生图：使用图片工具直接执行，尽可能同时提供风格参考图和目标图。若图片工具不支持附加本地 Skill 资源，不要假装已经把风格参考图传入；改用风格说明，必要时说明匹配度可能降低。若用户仅要提示词，提供可复制成稿即可。

图片生成时，避免输出技术参数或空洞的工具说明代替成品。工具不可用时明确说明，不声称已经出图。

### 5. 自检与迭代

检查：

- 目标人物/物体/场景的**核心内容**是否准确，用户指定细节是否被保留；新增背景/物体是否必要且合乎主题。
- 视觉上是否确实像**手绘不透明水粉/轻厚涂**，而非照片、纯矢量、卡通赛璐璐或透明水彩。
- 是否出现可见短笔触、层叠色块、细腻纸张颗粒与复古哑光质感。
- 是否在适度补景、扩大画幅和强化层次时，避免了喧宾夺主、凭空增加关键人物、挪用参考图具体内容。
- 色彩是否具有柔和冷暖对比，是否被强行加上参考图的元素。
- 是否符合输出画幅、头像圆形裁剪安全区、文字处理等用途要求。

如有明显问题，优先修复**内容保真**，其次修复笔触与色彩。细分标准见 `references/prompt-templates.md`。

## 常用一句话调用

> 用 `vintage-travel-gouache-reference` Skill，把这张目标图片改成《海边度假》参考图的复古旅行海报厚涂风；保留主体及关键细节，允许适度补全背景、丰富环境层次与优化取景，但不要把参考图的邮轮、灯塔或巨大太阳机械复制过来。

## 默认行为

- 未指定尺寸/比例：**风格迁移原则上沿用目标图比例**；需要补景或适配用途时可延展边缘，不能无故裁切主体；全新创作按主题选择合理比例，而不是强制 2.8:1。
- 用户没有额外交代时：默认采用 **1 级适度扩展**，仅为画面完整性、美感和空间层次做少量合理新增；明确要求保持原样时回退到 **0 级严格复刻**。
- 用户已指定水彩、墨绘、低饱和、夜色、民族服饰、人物肤色或阵营颜色时：尊重其要求；必要时只借鉴参考图的笔触构成，不能用统一调色覆盖。
- 无文字要求时：不添加海报标题、标语、Logo 或水印。
- 无图像输出请求时：只给说明或提示词，避免多余的图片生成。
