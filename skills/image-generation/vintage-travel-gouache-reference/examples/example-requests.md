# Skill 调用示例

## 1. 人物插画改画风

用户说：「把这张三国人物图转成复古旅行海报厚涂风，人物仍在骑马，保持红色主题和侧面视角，最终做圆形头像。」

正确处理：保留人物、马、服饰、姿态、红色主题及侧面视角；采用不透明水粉短笔触和复古哑光纹理；构图拉远并居中，预留圆形裁切安全区。可补充远山、天空或树影以形成层次，但不增加抢镜的人物或机械复制邮轮和海岸。

## 2. 城市旅行照片改画风

用户说：「把我拍的城市街景变成《海边度假》那张图的风格，但楼房和招牌不要变。」

正确处理：保留主体楼房结构、重要街道关系和原有可辨识文字；用暖冷色块、复古纸纹与清晰笔触替代照片质感。可以合理延续街道两侧的次要建筑、增添少量云影或绿化；原图如果没有海，不能为了套画风加海。

## 3. 动物头像改画风

用户说：「这只狗保持毛色、斑纹和项圈，做成 1:1 的复古厚涂插画。」

正确处理：准确保留犬只的毛色、斑纹与项圈；可以为头像添加简洁、与季节/场景相符的绘画背景，通过光影和短笔触表达复古质感。主体完整位于圆形安全区。

## 4. 原创旅行海报

用户说：「画一张原创的高山火车旅行插画，16:9，不写任何标题，参考《海边度假》的绘画质感。」

正确处理：可以使用远近景分层、温润光照和漂亮的海报式视觉节奏，但**主体是高山火车**，不是邮轮。无需添加灯塔、棕榈树、巨大太阳。

## 5. 只要提示词

用户说：「给我一个适用于其他绘图工具的英文提示词。」

正确处理：返回 `references/prompt-templates.md` 中的英文模板并替换占位符；不自动生成图像。

## 6. 对原图进行画幅扩展

用户说：「把这张竖图做成 16:9 复古厚涂横幅，画面左右可以适当发挥，主角不要动。」

正确处理：保留主角身份、姿态和重要道具，优先向左右自然补景；根据原图的地平线、光源、消失点延展道路、山体、植物或建筑环境。避免直接拉伸原画或为了凑宽加入不相关的灯塔、邮轮等。

## 7. 用户要求完全不增加内容

用户说：「只是转换成这个画风，所有内容原样保留，一个元素都不要加。」

正确处理：此时启用 Level 0 严格复刻，关闭默认内容扩展。只改变水粉笔触、光影、颗粒和复古调色，不改动原图构图或增加配景。
