# v2.0 用法示例（无需风格参考图片）

## 1. 海滨酒店图

用户：用这个 Skill 把我拍的海滨酒店变成复古旅行插画，建筑和海岸保留，允许适度扩景。

执行：只输入目标海滨照片。使用 `references/prompt-templates.md` 模板 D 与全局天空约束。保留白色建筑、棕榈、海面、堤岸和视角；近海有短弧形笔触，天空几乎平整，少量云朵局部柔和叠色。可增加少量符合当地环境的花木，不加巨轮/灯塔/巨大太阳。若原图没有大片云，应保留清朗天空。

## 2. 荒漠道路与渺小独行者

用户：把我的荒漠黄昏照片转成同系列插画，人物保持很小，地面可以更丰富。

执行：只输入目标荒漠照片。使用模板 E。保留远方人物、道路引导线与山谷比例；天空作为安静的低笔触留白；沙地、道路和山崖的细小结构和光色可以丰富。不要把人放大、增加城堡或将画面自动变为大红色油画夕阳。

## 3. 历史人物头像

用户：把骑马人物做成复古旅行插画，蜀国红色主题，1:1，最终裁圆形。

执行：只输入用户提供的人物图；尊重其历史人物造型、红色主题、骑马动作；镜头合理拉远、人物居中、保留圆形裁剪安全区；天空几乎平整，人物和马使用细笔触，背景适度补远山但不抢镜。

## 4. 城市建筑旅行海报

用户：把城市街景照片改成这种插画风格，楼的轮廓、数量、可辨识招牌不能变。

执行：保护楼体、招牌与透视。大墙面干净，局部装饰笔触；天空平滑薄涂，街道采用适度结构性色块。仅允许非常轻微的边缘补景。无要求不添加标题。

## 5. 全新文字创作

用户：画一张原创的雪山火车旅行海报，16:9，无文字。

执行：遵守雪山火车主题和气候；使用复古海报造型、轻薄干净的天空、细腻冷色雪山、火车精细轮廓与局部冰雪/岩石笔触；不加入海洋、棕榈、邮轮或过大的金色太阳。

## 6. 严格不扩景

用户：所有背景、人物、画幅一模一样，只换画风。

执行：L0 严格模式。关闭所有配景和视角优化，只调整复古水粉画法、色块与按区域控制笔触。天空同样必须轻薄。

## 7. 用户指出“天空厚涂太重”

用户：不改其他，天空的油画纹理太重了。

执行：只使用 `references/prompt-templates.md` 中模板 F 局部修复天空，把斜向长纹改为平滑哑光水粉底色；不改变原图水面、建筑、山岩、人物和画幅。若工具不支持局部蒙版，至少在生成提示词里加强天空约束。
