# 分区域绘画质感控制（必须遵守）

> **核心目标**：保留原版精致商业插画的局部笔触，同时修正上一轮测试中“天空厚涂过重”的失真。下述 0–5 是视觉相对强度（0 ≈ 看不见笔触；5 ≈ 极粗厚笔触），不是生成模型的数值接口。

| 区域 | 推荐笔触强度 | 如何画 | 严格避免 |
|---|---:|---|---|
| **天空底色 / 大面积负空间** | **0–1/5** | 大片连续、轻柔的哑光不透明水粉色面，低反差微妙色调变化，均匀精细颜料微颗粒；正常观看尺度几乎不可见笔触 | 全天空斜向笔划、平行长刮痕、大片明显油画刀痕、凸起笔脊、横跨天空的螺旋纹或反复涂抹 |
| **云朵** | **1–2/5** | 乳白/奶油/桃橙的轻柔分层，轮廓有手绘质感；笔触集中在云缘和局部亮暗转折，体积圆润而不过度立体 | 厚重浮雕式云朵、锯齿状乱划、整片天空被油彩搅动、为了“充实背景”强加过量云墙 |
| **远山、远景** | **1–2/5** | 清晰概括的轮廓，低对比空气透视，柔和色块分层 | 与近景一样锐利粗重、用粗糙纹理淹没远景 |
| **建筑、船舶、人工结构** | **1–2/5** | 平整哑光墙面，结构清楚、细节精致；局部沿边缘和阴影有少量小笔触 | 立面像粗糙泥塑、透视破碎、表面满是油画刮痕 |
| **人物 / 动物主体** | **2/5** | 准确的剪影和身份特征，恰当局部笔触，五官/表情/道具可辨 | 涂抹到五官不清、手脚和服装结构错乱 |
| **岩石 / 沙地 / 道路** | **2–3/5** | 在地貌形体和明暗交界处使用带方向的短促色块；地面整体仍维持大色面 | 每寸地面刻成同样密度的长条刮痕、假纹理过强 |
| **海水 / 湖面** | **3/5** | 沿海浪/水流方向安排断续、弧形或横向短笔触，微细暖光反射；远水纹理略细，近水更明显 | 波浪像随机刮痕、到处一模一样的高频纹路、塑料光泽 |
| **树冠 / 植被** | **2–3/5** | 依据枝叶生长方向点划、压笔、块状明暗，结构优先 | 全画通用一层颗粒噪声、枝叶沦为乱涂漩涡 |
| **纸面微颗粒（全画）** | **0–0.5/5** | 只有放大时可察觉的细小哑光纹理，用于消除数字光滑感 | 粗麻布、明显纸纤维、脏污、裂纹、scratched canvas、heavy grain |

## 天空与云朵的辨析

**天空底色**是画面里最安静的视觉区域，呈现柔和平整的灰蓝色、自然透光感和非常淡的颜料颗粒。大气层次来自细腻色相过渡，不是机械重复笔触。

**云朵**才允许出现可辨认的轻度手绘分层，但也是“柔和、有结构的水粉色块”，不是厚重的凸起油彩。光线只在局部云边形成奶油色和淡金色，避免大面积纯橙覆盖。

### 正面指令（必须加入最终 prompt）

中文：
> 天空请用**几乎平滑的薄层哑光水粉底色**绘制，具有极细微、低反差的颜料颗粒和柔和色调过渡；在正常观看尺寸下不要看到方向性笔痕。仅云朵边缘存在轻柔的局部叠色笔触，海面、岩石、树冠才使用更明显的节奏性短笔触。整体是精致复古商业插画，而非全画厚油彩。

English:
> Paint the open sky as **broad, nearly smooth, thin-looking matte gouache color fields**, with only very subtle, low-contrast pigment micrograin and gentle atmospheric tonal shifts. At normal viewing size, the sky must show **no obvious directional brush marks**. Restrict visible localized brushwork to the soft edges of clouds, rhythmic waves, rocky contours and foliage. Refined vintage commercial illustration, **not an all-over impasto oil painting**.

### 天空负面指令（必须加入）

中文：
> 禁止整片天空的明显斜线笔触、厚油彩、刮刀纹、划痕、粗画布纹、螺旋状涂抹、浮雕颜料堆积；不要把晴空填满戏剧化云墙。

English:
> No thick impasto sky, no diagonal rake marks, no repeated directional hatching, no scratched canvas, no palette-knife ridges, no swirling oil-paint streaks across the sky, no excessive cloud banks in an originally clear sky.

## 分辨率和主体尺度

- 对 16:9 / 4:3 海滨图：海面中近景可以呈现细笔触；上方天空必须安静，建筑的细节应由准确结构而非密集刮痕体现。
- 对竖版荒漠图：大面积天空尤其需要保持留白和细微色调；地面用少量受地形控制的笔触增加厚度，远景虚实层级清楚；原图人很小时，不擅自放大成半身肖像。
- 对人物/头像：人物五官、衣纹和装备局部精细，背景更简洁，不能让笔触与人物同等抢镜。

## 单项强制校验

**把画面缩小到正常观看尺寸**：如果天空的长斜线、刮擦和油彩皱褶依然清晰可见 → 必须修复天空；如果只能看到柔和色面和轻微颗粒 → 通过。
