# 实际生成差异与交付验收（2026-11-19）

对照对象：用户最初提供的《海边度假》插画（风格目标），以及两张旅行照片的“有参考图”转绘与“仅文字”转绘。这里的结论是视觉观察，不是控制随机种子后的严格 A/B 科学实验；结果还会受到画幅、模型随机性和当次提示词影响。

## 两次输出的主要区别

| 维度 | 旧版：有风格图 | 旧版：文字-only | v2.0 目标 |
|---|---|---|---|
| 造型 | 海滨建筑结构较精致、复古海报辨识度较强 | 略松散，更像泛印象派油画 | 明确以精致商业海报为第一优先 |
| 天空 | 可见成排、偏长的斜向笔痕/刮擦纹 | 大块笔触和涂抹更松、更显眼 | **薄层平滑哑光水粉 + 极细颜料微颗粒** |
| 云朵 | 立体但偏厚 | 较奔放、偏油画云 | 软质叠色，笔触只局限云缘 |
| 水面 | 方向性和明暗关系较清楚 | 也有水体笔触，整体更自由 | 保留局部水浪笔触，细节不被“修天空”误伤 |
| 配色 | 蓝与金对比更鲜明 | 粉紫过渡相对更多 | 沿用目标场景色相，克制的蓝金关系 |
| 质感分布 | 所有区域都有明显笔触 | 全画都偏粗 | **纹理强度因区域而异，天空最低** |
| 对原图改动 | 有限扩景，部分天空云层丰富 | 画幅拼贴且云层增加 | 多目标图独立出图；保留天空留白，适度补景 |

## 对根因的修正

- 原版把 `Painterly Impasto`、`visible brush strokes` 放到全局正面提示，生成器可能误以为天空也要不断强化油画笔触。
- v2.0 主标签改为 `refined mid-century editorial travel poster / opaque matte gouache`，只在海、石、树的局部提到“明显笔触”。
- 原版用了“云层短笔触/厚实造型”，但缺乏天空底色与云朵的明确区别；v2.0 严格拆开两者。
- 原版对“纸张纹理”缺少上限，容易产生粗刮擦；v2.0 只允许非常淡的微颗粒。
- 原版常强调“丰富天空”；v2.0 将晴空留白作为有意设计，不能为了装饰无故填满云朵。

## 快速视觉验收（先看前两条）

| 项目 | 通过标准 | 失败时的动作 |
|---|---|---|
| **天空（硬门槛）** | 正常显示大小几乎无长方向性笔痕；天空平滑有细微颗粒 | 优先使用“局部纠偏 F”；**不要**同时加强全画笔触 |
| **云（硬门槛）** | 云朵分层温柔，有适度塑形，不厚重；晴空留白充分 | 减少云量与浮雕厚度 |
| 海报精致度 | 建筑/主体剪影清楚、形体可信、可读性高 | 加强结构明确与商业插画造型，弱化泛印象派 |
| 水/地面 | 有材质专属的方向性笔触，近远景有区别 | 只局部增强该区域的短笔触 |
| 色彩 | 柔和复古、暖冷关系自然，尊重场景固有色 | 降低霓虹饱和/过量粉紫、恢复真实场景主色 |
| 内容保真 | 主体、姿态、建筑关系、时段天气保留 | 优先修复主体，降低内容扩展等级 |
| 扩景程度 | 新增的物体自然且不抢主角，天空保留空间 | 删除夸张云墙、无关船只、强行加日落 |
| 输出结构 | 多张目标图独立输出，除非用户要求拼贴 | 改为分别输出并维持原比例 |

## 修复策略的先后顺序

1. 先用单独的天空局部编辑把纹理降下来（不重绘其他区域）。
2. 若整体依旧偏油画：替换全局 `impasto` 为 `matte opaque gouache`，加上 `refined commercial travel poster illustration`。
3. 若风格太平：只增强浪花、岩石、树冠、细节边缘的短笔触，而不是给天空加笔触。
4. 若色彩偏艳：减少紫粉和高饱和蓝，保持低/中饱和暖冷平衡。
5. 若背景过度扩充：缩回 L1，保留原始天空与远方留白。
