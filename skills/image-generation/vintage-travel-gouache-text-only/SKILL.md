# Vintage Travel Gouache · 复古旅行海报水粉插画（v2.0 · Text-only）

## 目标和最重要的改变

将**精致的中世纪欧美旅行宣传画（mid-century painted travel poster）**、**不透明水粉（opaque gouache）**和**有选择的手绘短笔触**结合，用纯文字规则就能稳定描述画风。不需要、不请求、不自动读取或附加任何额外的「风格参考图」。图像编辑时只需用户的**目标图片**；纯文字创作时无需图片。

**最重要的硬约束：天空必须轻薄、平滑、克制。** 不要把「厚涂 / impasto / 明显笔触」理解成整张画都要刻满笔痕。天空底色几乎不见方向性笔触；云朵局部塑形；海浪、岩石、植被才允许更明显的节奏性笔触。相比印象派油画，本 Skill 更接近**精致、形体清晰、哑光、表面干净的复古商业插画**。

## 触发条件和任务识别

- **目标图片 → 插画（默认）**：保留图片主题、关键主体、透视与地景关系，执行适度艺术化扩景。
- **目标图片 → 严格画风转换**：若用户要求原样保留，关闭新增物件与构图改动。
- **文字 → 原创旅行插画**：在文字约束下原创场景，应用本 Skill 的画法。
- **用户只求风格分析/提示词/修改 Skill**：只回答或修改所需内容，不擅自出图。

已知约束不重复问；用户未指定画幅时，编辑图片原则上沿用目标图宽高比。多张目标图**分别生成**，除非用户明确要求拼贴、组图或对照图。

## 五条硬规则（无风格参考图也必须遵循）

1. **先保留内容**：人物身份/可见特征、动作、建筑形态、标志性道具、重要数量与原有场景关系优先。默认允许适度扩景（Level 1），不编造重要剧情或地标。
2. **先定海报形体**：轮廓清楚，具有编辑插画级别的造型概括。既不是摄影滤镜、扁平矢量，也不是松散失焦的印象派油画。
3. **分区域分配笔触**：天空底色 0–1/5；云朵 1–2/5；建筑 1–2/5；人物 2/5；山石/地面 2–3/5；海水/树冠 3/5。尺度是**相对视觉强度**，不是生成模型的数值 API 参数。详见 `references/region-texture-map.md`。
4. **天空优先**：以大而连续、低反差、哑光的不透明水粉色面和*微弱均匀颜料颗粒*呈现天空；在画面正常观看尺寸下不应看到成排斜线、刮刀痕、强烈卷曲大笔触、粗糙油彩浮雕或厚重画布刮擦。天空越大，越要保留安静留白。允许缓和的色相/明度变化，但不堆叠大规模戏剧性云朵。
5. **克制的复古配色**：通过柔和冷暖互补、暖金光、奶油亮部、灰蓝/青绿暗部表达浪漫旅行气质；保留目标图固有色、季节、光照及指定主题色。**不要**把所有场景都改为粉紫橙日落。

## 执行流程

### 1. 建立目标内容约束

从目标图或用户描述提取：`主体 / 身份特征 / 姿态 / 主要构图 / 环境 / 时段天气 / 必留色彩或文字 / 画幅 / 允许扩景程度`。

内容扩展等级：
- **L0 严格**：仅改画法，不增删物件或调整构图。
- **L1 适度（默认）**：合理延长天空、岸线、地形、远景、植被与画面边缘；少量不抢主体的配景；可轻微调取景，但不改变情节。
- **L2 较自由**：仅用户明确授权时明显扩大场景、增加配景；核心主体仍保真。

若原图天空清澈宽阔，即便 L1 也**优先保留天空留白**，不可因为“可扩景”就添加大片云墙或夸张太阳。新增元素必须合理、从属且与透视、光源相符。

### 2. 应用不可变的视觉骨架

将画面归类为 `mid-century editorial travel-poster illustration`，而非 `impressionist oil painting`。

视觉骨架的优先级：

1. **准确、优雅的形体与海报式画面组织**：清晰剪影；前中后景；有控制的装饰性概括；建筑线条干净，透视合理。
2. **哑光、不透明水粉色块**：相邻色面细腻叠置，质感主要来自细微的色差和边缘处理，而非普遍厚涂。
3. **质感依材质而变化**：天空近乎平整；云柔软；海浪有方向；山石有结构；房屋/人物笔触更细。
4. **克制的色彩和光**：温润暖光与平衡冷影，有空间纵深，有复古印刷的温柔感觉。
5. **极轻微统一的纸面微颗粒**：用于消除塑料感，但不能变成噪声、划痕、破损纸张纹理。

**不要把 'Painterly Impasto' 或 'thick oil paint' 当作全图正面主标签。** 如需出现，仅描述 `selective localized impasto on water highlights, foliage and rocky edges`。默认主风格标签为 `refined matte gouache travel-poster illustration`。

### 3. 应用区域纹理控制（关键）

务必阅读 `references/region-texture-map.md`，尤其天空和云朵。只在需要的区域使用明显的笔触，不允许在整个背景天空铺满相同方向的短线。天空底色必须比海面和岩石**至少低两个等级的视觉笔触强度**。

### 4. 根据主题选择配色，而非全场景硬套滤镜

见 `references/palette-and-lighting.md`。海滨场景可用深海蓝 × 低饱和灰蓝天空 × 奶油暖光；荒漠场景可用赭石、沙金与灰紫山影，不应被迫出现青绿海色或桃粉云。天气、日期、时段按用户要求。

### 5. 构建成品提示词

按 `references/prompt-templates.md` 的结构拼接：

`[目标图核心内容] + [允许的 L0/L1/L2 扩展] + [复古旅行海报精致造型] + [不透明哑光水粉] + [分区域笔触规则（天空优先）] + [主题配色与光] + [负面约束] + [画幅]`。

对于图像生成/编辑工具：**仅上传用户要转换的目标图，不上传任何本 Skill 的风格参考图**。不要借用上一张已生成的图片作为隐形风格参考，除非用户明确要求。使用文本风格 DNA 作为唯一风格依据。若图片工具支持局部重绘，天空笔触过重时优先局部修复天空，其他区域尽量不动。

### 6. 交付前检查（逐项必过）

- **天空质地**：以正常显示尺寸观看，基本读不出方向性笔痕；只是柔和的哑光色面和微弱细颗粒。天空如出现成排斜向笔划、刮刀纹或浮雕状厚涂，判为**不合格**，必须首先修正。
- **云朵**：可以蓬松、层次分明，但不能连同整片天空形成夸张的油画堆叠；清朗原图不能无故长出过量戏剧性云层。
- **差异化笔触**：海水/岩石/植被有自然节奏，建筑、人物形体清晰，全部素材不可套同等强度颗粒纹理。
- **风格定位**：像精致的中期复古商业旅行插画，不像梵高式油画、泛印象派厚涂、AI 风景照滤镜或矢量扁平画。
- **内容和扩景**：主体、姿态、场景核心不漂移；新配景合理、不喧宾夺主；无无依据文字/Logo。
- **构图比例**：画幅和主体大小符合请求，多图默认独立输出。

更详细的对照、失败判断和修复提示见 `references/comparison-and-qa.md`。

## 可直接调用的一句话
