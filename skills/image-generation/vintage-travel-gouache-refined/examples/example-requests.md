# 使用示例
- **海滨照片**：「使用 vintage-travel-gouache-refined 将酒店海岸照片改画成精致复古旅行海报。天空几乎平滑无明显笔痕，海浪有优雅短笔触，保留海堤、建筑与棕榈树。」
- **荒漠照片**：「保留小人物、道路和两侧山丘，维持开阔天空留白；地面有结构性短笔触，天空只含轻微颜料微颗粒。」
- **人物头像**：「使用 refined gouache 画法，保留服饰和主体颜色，人物居中，圆形裁切后完整，背景可适度丰富。」
- **文字原创**：「创作复古旅行海报里的山间火车，哑光水粉、准确形体、天空轻薄，无标题和水印。」
- **天空单独修复**：「只移除天空的斜向油画刮擦纹，保留海浪、建筑和山石的细节。」
