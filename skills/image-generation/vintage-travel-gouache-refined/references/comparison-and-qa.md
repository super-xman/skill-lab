# Refined Gouache · 质量检查与局部纠偏

本风格以 **精致20世纪中期复古商业旅游插画**为目标，所有规则均来自文字描述。无需额外风格参考图；`examples/` 图片只供 README 展示，不作为生成输入。

| 区域/问题 | 通过标准 | 纠偏方式 |
|---|---|---|
| 天空 | 大色面近乎平整，只有细密、低对比微颗粒 | 清理方向性斜笔痕、刮刀纹、卷曲油画笔触 |
| 云朵 | 柔和块面塑形，云缘局部保留轻笔触 | 减少厚涂，晴朗原图保持留白 |
| 建筑人物 | 轮廓、结构与辨识度准确 | 优先恢复主体，弱化全局纹理 |
| 水面 | 具有方向与流动感的精致短笔触 | 保留浪花细节但不让天空同样厚涂 |
| 山石道路 | 结构性短笔触和复古色面 | 避免无方向的随机噪声 |
| 配色 | 适应原图时间、地点和固有色 | 不强制粉橙日落滤镜 |
| 扩景 | L1 适度合理，新增配景不抢主体 | 删除无关元素，恢复原图场景 |
| 多图输出 | 默认各自单独出图 | 只有用户要拼贴时才生成拼贴 |

局部修复提示词：**只修天空和云朵质地**；将明显斜向笔痕和厚油画刀纹改为薄而平整的哑光水粉色面，保留原有色相、时段、留白与细微颗粒。不要改变人物、海浪、山石、建筑或画面构图。
