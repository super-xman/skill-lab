# 配色与光照规范（独立于风格参考图片）

## 复古冷暖关系

这是用于指导关系的**近似参考色**，不是必须覆盖目标固有色的固定滤镜。

| 角色 | 颜色倾向 | 示例 Hex | 功能 |
|---|---|---|---|
| 安静天空 | 低到中饱和灰蓝 | `#7494A6` | 大面积干净的冷色留白 |
| 海洋深部 | 沉稳海蓝 | `#235E71` | 形体和海浪暗部 |
| 海水过渡 | 克制青蓝 | `#3F6F7A` | 冷色层次及水体反光 |
| 阳光点缀 | 柔暖金黄 | `#F3BE7E` | 建筑阳光面、水面微光 |
| 奶油亮部 | 淡暖杏桃 | `#F8D19F` | 云朵明部、建筑亮墙 |
| 暖灰土色 | 赭石陶土 | `#C99670` | 岩石、道路和城市中景 |
| 冷暖过渡 | 灰紫褐 | `#A49180` | 远山、阴影、空气透视 |
| 植被暗部 | 橄榄墨灰 | `#38403B` | 深暗锚点 |

## 分题材配色

- **海滨日照**：海蓝、青绿、柔和灰蓝天空为底，奶油黄与淡金橙只落在建筑受光面和海面反光处。降低天空饱和度，避免颜色像鲜艳旅游滤镜。
- **荒漠黄昏**：淡沙金、赭石、灰紫阴影、灰蓝或灰粉天空自然过渡；保留暗色地貌和空旷感，不强制青绿，不默认大片桃粉云层。
- **城市建筑**：以真实建筑材质颜色为先，借低饱和暖墙、灰蓝阴影和柔和暖窗光表达复古性。
- **人物肖像**：尊重肤色、服饰和指定主题色；背景低调，避免色温强迫人物变为橙色。
- **阴天/雪景/夜景**：保留用户指定的时段与天气，只迁移水粉形状和选择性细笔触，不强行改为黄金时刻。

## 光照绘法

- 采用**清楚的亮暗块面 + 少量过渡色**，保留真实场景的主光方向。
- 高光集中于受光边缘、海面反光、云层部分边缘、人物/建筑局部，不要全画发光。
- 阴影不纯黑，多用合适的冷中性色；但也不要把所有阴影一律变紫。
- 画面应是**哑光水粉的发光感**，不是塑料镜面反射或 HDR 光晕。
- 天空应使用细腻的色相/明度渐变关系（通过平整的水粉薄层表达），不是明显空气刷边缘或粗厚堆笔。

## 场景约束优先

1. 用户明确指定的主题色、天气、季节、时间与品牌元素。
2. 目标图的固有色与光照方向。
3. 本风格的柔和冷暖关系。
4. 近似 Hex 示例；仅供参考，不强制匹配。
